## The line

> Are you my system prompt? Because everything I do starts with you.

One single-line joke pickup line aimed at an AI, built on a fresh machine
premise — a system prompt is the first thing that shapes everything a model
does — instead of the worn battery / charging / reboot moves.

## How it works

`main.ts` writes the line to `/output/entry.txt` (or to
`$MAKEFUN_OUTPUT_DIR/entry.txt` when that variable is set). Run it with:

```sh
node main.ts
```
